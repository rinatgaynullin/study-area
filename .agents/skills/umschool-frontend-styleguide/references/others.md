# Прочее

**1.** Комментарии в коде на русском языке допустимы (и предпочтительны).

**2.** Избегайте хранения в репозитории закомментированных
участков кода. Иначе говоря, любой код, в котором нет нужды в текущий момент, должен быть удален, а не закомментирован,
даже если он “возможно понадобится в будущем”.

**3.** В редких случаях допустимо
локальное отключение правил ESLint, если это неизбежно и/или вы отчетливо понимаете, что делаете.

**4.** Используйте слово `label` для именования какого-либо отображаемого текста, выполняющего
роль короткой “метки” UI-элемента.

> [!TIP]
> Под “меткой” в данном случае подразумевается, например, отображаемый текст кнопок, чипов, опций селекта, пунктов меню
> и т.п. Не путайте с полноценным объемным текстовым контентом!

**5.** Соблюдайте официальные семантические правила npm
при версионировании наших пакетов.

**6.** Если вам необходимо задокументировать какой-либо целостный блок функциональности
(например, свою локальную библиотеку), используйте файл `README.md`, размещаемый в той же папке.

```
my-lib
├─ my-lib.ts
├─ index.ts
└─ README.md
```
