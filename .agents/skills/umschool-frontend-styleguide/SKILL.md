# UMSchool Frontend Styleguide

Следуй правилам из `references/` как источнику истины для frontend-кода UMSchool.

## Порядок работы

1. Прочитай [общие принципы](references/about.md).
2. Определи технологии и аспекты задачи.
3. Прочитай только относящиеся к ним документы из списка ниже. Для сквозных изменений используй несколько документов.
4. Применяй обязательные формулировки как требования, а рекомендательные — как предпочтения.
5. При ревью называй нарушенное правило и предлагай исправление, согласованное с примерами из документации.
6. Если локальная практика противоречит этому skill, явно укажи конфликт и следуй документации, если пользователь не распорядился иначе.
