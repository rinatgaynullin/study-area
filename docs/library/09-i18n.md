# 9. Интернационализация

## Назначение

Русский и английский встроены; любой другой язык — плоская таблица
`Messages` (`lower_snake` ключ → строка) от хоста. Частичная таблица
допустима: недостающие ключи берутся из встроенных переводов. Переводчик один
на редактор, его `t` получают тулбар, диалоги, адаптеры загрузки и
возможности хоста.

## Когда использовать

- `locale: 'en'` — без таблицы, английский уже в бандле.
- Другой язык или свои подписи (`labelKey` своих пунктов) — опция/проп
  `messages`.
- Точечная правка строки — `messages: { en: { toolbar_bold: 'Heavy' } }`.

## Интерфейс

Сигнатуры — [14-api-reference.md](14-api-reference.md#i18n).

| Член | Где | Что делает |
| --- | --- | --- |
| `locale` | опция ядра и `createRichEditor`, проп `RichEditor`, параметр виджета Django | Активный язык; по умолчанию `'ru'` (`DEFAULT_LOCALE`) |
| `messages` | там же | `Record<string, Messages>`: язык → таблица; накладывается поверх встроенных |
| `setLocale()`, `setMessages()`, `refreshLabels()` | `RichEditorUi` | Смена на лету; тулбар и диалоги пересобираются |
| `ru`, `en` (`ruMessages`, `enMessages` во Vue) | экспорт | Встроенные таблицы — отправная точка для нового языка |
| `createI18n({ locale?, messages? })` | экспорт | Переводчик для своего интерфейса: `t`, `locale`, `setLocale`, `setMessages` |

Порядок поиска ключа: таблица хоста для языка → встроенная для языка →
таблица хоста для `ru` → встроенная `ru` → сам ключ. Плейсхолдеры `{name}`
подставляются из второго аргумента `t(key, params)`.

### Ключи

Полное имя — префикс плюс суффикс из таблицы; в фигурных скобках —
плейсхолдеры. Источник истины — `packages/editor-core/src/i18n/ru.ts`;
наборы ключей `ru` и `en` совпадают.

| Префикс | Суффиксы |
| --- | --- |
| `toolbar_` | `bold italic underline strike heading heading_level{level} paragraph bullet_list ordered_list` |
| `toolbar_` | `blockquote code code_block link table align align_left align_center align_right align_justify` |
| `toolbar_` | `text_color highlight undo redo clear_format horizontal_rule subscript superscript` |
| `toolbar_` | `image audio file formula_math formula_chem more label` |
| `table_` | `insert rows cols with_header add_row_before add_row_after delete_row` |
| `table_` | `add_column_before add_column_after delete_column merge_cells split_cell` |
| `table_` | `toggle_header_row toggle_header_column delete_table` |
| `link_` | `title url url_placeholder text open_in_new_tab apply remove invalid open` |
| `link_` | `style style_default style_strong style_muted` |
| `color_` | `reset custom` |
| `audio_` | `title record stop pause resume play cancel insert rerecord permission_hint` |
| `audio_` | `unsupported remaining{time} duration_limit{seconds} position` |
| `file_` | `attach insert_content download` |
| `formula_` | `title_math title_chem tab_math tab_chem templates preview insert save cancel remove` |
| `formula_` | `empty invalid input_hint loading` |
| `formula_categories_` | `basic fractions roots scripts sums integrals limits matrices greek relations functions` |
| `formula_categories_` | `chem_reactions chem_states chem_isotopes chem_patterns` |
| `upload_` | `image audio file` |

Свои ключи (для `toolbarItems`, `features`, `linkStyles`) должны быть во всех
таблицах хоста: встроенные их не содержат, и ключ покажется как есть.

### Строки MathLive

У поля ввода формул своя система строк (контекстное меню, подсказки). MathLive
поставляется без русского; пакет добавляет таблицу `mathliveRu` и подключает
её через `MATHLIVE_STRINGS` (`{ ru: mathliveRu }`) при загрузке MathLive.
Другой язык меню — добавить ключ в `MATHLIVE_STRINGS` до первого открытия
диалога формул; отдельного API нет.

## Пример

```ts
import { createRichEditor, en } from '@rich-editor/core';

const de = { ...en, toolbar_bold: 'Fett', toolbar_italic: 'Kursiv' }; // остальное пока по-английски

const editor = createRichEditor({ element, locale: 'de', messages: { de } });
editor.setLocale('en');
```

```vue
<RichEditor v-model="html" locale="en" :messages="{ en: { toolbar_bold: 'Heavy' } }" />
```

## Ограничения

- Язык без таблицы (`locale: 'de'` без `messages.de`) даёт русский интерфейс.
- У `RichEditorCore` без оболочки `setLocale()` меняет только то, что
  читается через `t` в момент вызова; смонтированные плееры и вложения не
  перерисовываются.
- Вьюер подписей не рисует (кроме имени формулы для читалки), локали у него
  нет.
