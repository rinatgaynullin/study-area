# 15. Ограничения, статус и расхождения

## 15.1. Известные ограничения (кратко)

Полный текст с обоснованиями — `LIMITATIONS.md`. Сводка по коду:

| Область | Ограничение |
| --- | --- |
| Химия | Только уравнения и нотация; структурных формул (кольца, связи) нет. Точка расширения — узел-сосед на SMILES/MOL (ADR 0005) |
| LaTeX → MathML | MathLive теряет тело у `\overline`, `\underline`, `\overbrace`, `\underbrace`, `\overrightarrow`; ломает `\longrightarrow`, `\xrightarrow`, `\iff`, `{}^{14}_{6}\mathrm{C}`. Шаблоны их обходят, `repairMathML` чинит структуру, но потерянное содержимое не восстановить |
| Повторное открытие чужого MathML | без TeX-аннотации конвертация структурная (`mathml-to-latex`); экзотическая разметка может упроститься при сохранении |
| MathLive UI | русская таблица покрывает прозу; 13 `*-template` остаются LaTeX; экранная клавиатура отключена |
| Изображения | нет UI для alt, подписи, кадрирования; `alt` = имя файла; только resize с сохранением пропорций |
| Аудио | нужны `MediaRecorder` и доступ к микрофону; контейнер зависит от браузера, транскодирования нет; осциллограмма только у записанного в редакторе аудио |
| Формулы и читалки | имя формулы — её LaTeX (`role="img"`); речевого описания (SRE) и навигации по выражению нет |
| SSR | редактор и вьюер работают только на клиенте (DOMPurify, ProseMirror, MathLive нуждаются в DOM); `<RichContent />` под SSR отдаёт пустую оболочку |
| Совместная работа | нет realtime, комментариев, истории версий; undo/redo локальные |
| Legacy Froala | видео/iframe вырезаются; эмодзи-спаны с `background: url()` не рисуются; при **редактировании** теряются декоративные классы (кроме трёх на ссылках) и структура подписей картинок; `legacyEmbed` не редактируется; `legacy` читается один раз; проектные классы Froala (если были) не покрыты |
| Размер | редактор + TipTap ≈ 615 КБ, MathJax ≈ 965 КБ (лениво), MathLive ≈ 780 КБ (лениво) — цифры из `LIMITATIONS.md` |
| Не планировалось | режим физики, пользовательский редактор шаблонов, встроенное хранилище файлов, PWA/offline |

## 15.4. Места, где поведение стоит знать (не баги, но неочевидно)

- **Серверные и клиентские пределы не связаны.** `DEFAULT_LIMITS` клиента:
  аудио 10 МБ, файл 5 МБ; `settings.RICH_EDITOR` сервера: аудио 20 МБ, файл
  20 МБ. Серверный `FILE_TYPES` (`text/plain text/markdown text/csv`) уже
  клиентского `isTextFile` — `.json`, `.xml`, `.yaml`, `.log`, `.tsv`
  пройдут клиентскую проверку и получат 400 от сервера.
- **Серверный санитайзер мягче к `data:` в `href`** (nh3 применяет
  `url_schemes` ко всем URL-атрибутам) и **строже к `style`** (позитивный
  список свойств). Клиент при следующем открытии документ дочистит, но
  сохранённый на сервере HTML и то, что видит редактор, могут отличаться.
- **Поповер ссылки ставит `target="_blank"`**, если у ссылки не было
  `target`, тогда как диалог ссылки управляет этим чекбоксом. Ссылка,
  созданная без «новой вкладки» и затронутая в поповере, начнёт открываться
  в новой вкладке.
- **`insertRecording` без `uploadAudio`** кладёт blob напрямую через
  `toObjectUrl`, минуя проверку `maxAudioSizeBytes` пайплайна; предел размера
  в этом случае обеспечивает только рекордер (`onLimit('size')`).
- **`setHTML` не эмитит `onChange`** (`emitUpdate: false` по умолчанию) —
  после программной подстановки документа модель Vue не обновится сама.
- **`setLocale` у `RichEditorCore` без оболочки** не перерисовывает уже
  смонтированные node view (подписи плеера/вложения) — только новые.
- **Группы `color` и `align` в пресете `full` помечены `collapsible`, но не
  схлопываются**: в них дропдауны, а в меню «⋯» уходят только группы из
  обычных кнопок.
- **`features`/`toolbarItems`/`legacy`/`extensions` читаются один раз** —
  они формируют схему; для смены пересоздайте редактор.
- **MathML парсится как HTML**, не XHTML (ради сущностей MathLive) — это
  осознанное решение ADR 0004, но означает, что строгий XML-валидатор на
  стороне сервера может не принять `data-mathml` с `&ne;` и подобными.
- **Имя файла записи** — `voice-<timestamp>.<ext>`; `ext` выводится из MIME
  контейнера (`webm/ogg/m4a/mp3/wav`, иначе `webm`).

## 15.5. Точки расширения (вместо дорожной карты)

Формальной дорожной карты в репозитории нет; `LIMITATIONS.md` и ADR
называют направления, под которые оставлены точки расширения:

- структурная химия — узел-сосед `chemStructure` на SMILES/MOL (ADR 0005);
- доступность формул — speech-rule-engine уже транзитивная зависимость
  `@mathjax/src`, включить его вывод (LIMITATIONS «Accessibility»);
- совместное редактирование — TipTap поддерживает Y.js, ничего не
  подключено (LIMITATIONS «Collaboration»);
- полная сохранность классов Froala при редактировании — моделирование
  классов как атрибутов узлов, «если правка legacy-документов окажется
  частой» (ADR 0007);
- обёртка под другой фреймворк — повторить `rich-editor.vue` (~170 строк)
  вокруг `createRichEditor` (ADR 0008);
- веб-компонент поверх ванильного интерфейса — упомянут как возможное
  дополнение (ADR 0008).

Публикация пакетов: scope `@rich-editor` — заглушка, версии `0.1.0`,
`CHANGELOG.md` ведётся в разделе «Unreleased».
