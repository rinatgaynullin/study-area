# 15. Ограничения, статус и расхождения

## Назначение

Сводка того, чего библиотека не делает, неочевидного поведения, которое стоит
знать при интеграции, и расхождений между кодом и старыми документами. Код
считается источником истины. Полный текст ограничений с обоснованиями —
`LIMITATIONS.md` в корне.

## Ограничения

| Область | Ограничение |
| --- | --- |
| Химия | Только уравнения и нотация; структурных формул (кольца, связи) нет |
| LaTeX → MathML | MathLive теряет тело у `\overline`, `\underline`, `\overbrace`, `\underbrace`, `\overrightarrow`; ломает `\longrightarrow`, `\xrightarrow`, `\iff` |
| Чужой MathML | Без TeX-аннотации конвертируется структурно; экзотическая разметка может упроститься при сохранении |
| MathLive | Русская таблица покрывает прозу меню; записи `*-template` остаются LaTeX; экранная клавиатура отключена |
| Изображения | Нет UI для alt, подписи, кадрирования; `alt` — имя файла; только resize с сохранением пропорций |
| Аудио | Нужны `MediaRecorder` и микрофон; контейнер зависит от браузера, транскодирования нет; осциллограмма только у записи |
| Читалки | Имя формулы — её LaTeX; речевого описания и навигации по выражению нет |
| SSR | Редактор и вьюер работают только на клиенте; `RichContent` под SSR отдаёт пустую оболочку |
| Совместная работа | Нет realtime, комментариев, истории версий; undo/redo локальные |
| Legacy Froala | Видео и `iframe` вырезаются; эмодзи с `background: url()` не рисуются; при редактировании теряются декоративные классы |
| Размер | Редактор + TipTap ≈ 615 КБ; MathJax ≈ 965 КБ и MathLive ≈ 780 КБ грузятся лениво |
| Не планировалось | Режим физики, пользовательский редактор шаблонов, встроенное хранилище файлов, PWA/offline |

## Неочевидное поведение

- Пределы клиента и сервера не связаны: `DEFAULT_LIMITS` — аудио 10 МБ, файл
  5 МБ; `settings.RICH_EDITOR` — 20 и 20 МБ. Серверный `FILE_TYPES` уже
  клиентского `isTextFile`: `.json`, `.xml`, `.yaml`, `.log` получат `400`.
- Серверный санитайзер мягче к `data:` в `href` и строже к `style`
  (позитивный список свойств): сохранённый HTML и то, что видит редактор,
  могут отличаться.
- `setHTML()` не вызывает `onChange`; `v-model` после программной подстановки
  не обновляется.
- `insertRecording()` без `uploadAudio` минует проверку `maxAudioSizeBytes`
  пайплайна — предел держит рекордер.
- Поповер ссылки ставит `target="_blank"`, если у ссылки не было `target`.
- Группы `color` и `align` пресета `full` помечены `collapsible`, но не
  схлопываются: в меню «Ещё» уходят только группы из обычных кнопок.
- `legacy`, `features`, `toolbarItems`, `extensions` читаются один раз — для
  смены пересоздайте редактор.
- MathML разбирается как HTML, не XHTML (ради сущностей MathLive вида `&ne;`):
  строгий XML-валидатор на сервере может не принять `data-mathml`.

## Статус тестирования

| Слой | Что покрыто |
| --- | --- |
| Ядро (Vitest) | Санитайзер и контракт с Python, MathML-утилиты, SVG MathJax, каждый шаблон каталога, строки MathLive, round-trip документа, загрузки, рекордер (mock), тулбар, примитивы, оболочка, вьюер, legacy, токены темы, i18n |
| Vue (Vitest) | Монтирование, пропы, `v-model`, тема, i18n, exposed API, диалог формул, ошибки; вьюер |
| E2E (Playwright, desktop + mobile) | Три страницы демо: экспорт, враждебный HTML, формулы, тулбар, тема, legacy, картинки, поповер ссылки, клавиатура, standalone из статики |
| Standalone smoke | Монтирование одним module-скриптом, ленивые чанки, шрифты, вьюер с MathJax, чистая консоль |
| Django (pytest) | Санитайзер, вьюхи загрузки, виджет, поля, теги шаблонов |

Не покрыто: реальная запись с микрофона, реальные сетевые адаптеры, визуальная
регрессия, производительность на больших документах, Safari и Firefox.

## Расхождения кода и документов

| Документ | Что написано | Что в коде |
| --- | --- | --- |
| `ARCHITECTURE.md` | Модули `editor.ts`, `nodes/legacy-embed.ts` | Файлы называются `rich-editor-core.ts`, `nodes/legacy-embed-node.ts` |
| `ARCHITECTURE.md` («Testing») | Четыре слоя тестов | Есть ещё дымовая проверка standalone и pytest для Django |
| ADR 0003 | Масштаб формулы через `font-size`, SVG в `ex`, один кэш на все масштабы | Размер запекается в `px`; масштаб — параметр рендера `fontSizePx`, входит в ключ кэша |
| ADR 0002 | MathLive грузится лениво «только в Vue-пакете» | Ленивый `import('mathlive')` живёт в ядре (`ui/dialogs/formula-dialog.ts`) |
| ADR 0006 («Consequences») | Runtime-зависимости Vue-пакета — ядро и MathLive | Единственная зависимость `@rich-editor/vue` — `@rich-editor/core` |
| ADR 0001 (аддендум) | Упоминает `toolbar-state.ts` и ~50 вызовов команд в `rich-editor.vue` | После ADR 0008 этих файлов и вызовов нет |
| `LIMITATIONS.md` («Accessibility») | Доступность формул вне скоупа, SVG «фактически aria-hidden» | Формула — `role="img"` с `aria-label` из LaTeX в редакторе, экспорте и вьюере |
| `README.md` (Vue props) | Не сказано, какие пропы читаются один раз | Без watcher: адаптеры, `placeholder`, `formulaScale`, `linkStyles`, `minHeight`, `statusLine`, `ariaLabel`, `mathliveFontsDirectory` |
| `packages/django-rich-editor/README.md` | Параметр `limits` без описания ключей | Ключи клиентские: `maxAudioDurationSec`, `maxAudioSizeBytes`, `maxImageSizeBytes`, `maxFileSizeBytes` |
| Коммит «стиль под eslint-конфиг» | — | Файла конфигурации ESLint в репозитории нет |

## Точки расширения

- Структурная химия — узел-сосед на SMILES/MOL (ADR 0005).
- Доступность формул — speech-rule-engine уже транзитивная зависимость
  `@mathjax/src`.
- Совместное редактирование — TipTap поддерживает Y.js, ничего не подключено.
- Обёртка под другой фреймворк — повторить `rich-editor.vue` вокруг
  `createRichEditor` (ADR 0008).
