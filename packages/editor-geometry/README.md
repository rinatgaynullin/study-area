# @rich-editor/geometry

Спайк: интерактивная геометрия и графики функций для `@rich-editor/core` на
[JSXGraph](https://jsxgraph.org/). Статус — эксперимент на ветке
`spike/geometry-jsxgraph`, не для продакшена.

## Что делает

- Узел `geometry` (блочный атом): построение хранится текстом JessieCode в
  `data-geometry`, видимая область в `data-bbox`, высота в `data-height`.
  Документ остаётся обычным HTML.
- `geometryFeature()` — возможность редактора: узел, кнопка тулбара и диалог
  с текстом JessieCode и живым предпросмотром.
- `hydrateGeometry(root)` — поднимает доски во вьюере (`createRichContent`),
  который про геометрию не знает.
- JSXGraph грузится лениво при первом построении (~1 МБ, gzip ~250 КБ).

```ts
import { createRichEditor } from '@rich-editor/core';
import { GEOMETRY_MESSAGES, geometryFeature, hydrateGeometry } from '@rich-editor/geometry';

createRichEditor({ element, features: [geometryFeature()], messages: GEOMETRY_MESSAGES });

// Вьюер: после рендера HTML.
const dispose = hydrateGeometry(viewerElement);
```

## Что показал спайк

- Требования закрываются штатно: `glider` держит точку на графике функции и на
  сторонах фигур при любых изменениях, `functiongraph` по формуле из текста
  перестраивается при смене параметров (слайдеры) и самой формулы.
- JessieCode разбирает формулы пользователя без доступа к DOM; по умолчанию
  функции компилируются через `eval`, поэтому загрузчик переключает
  `JXG.Options.jc.compile = false` (режим интерпретатора). Проверено тестом с
  заблокированным `eval`: доска работает.
- `JXG.Dump.toJessie` не годится как формат хранения: это полный дамп доски с
  осями и служебными точками, а не правка авторского текста. Поэтому
  источник истины — скрипт автора, а положения хранятся отдельным слоем:
  `data-geometry-state` — JSON `{ имя: { value } | { coords: [x, y] } }` для
  слайдеров, точек и глайдеров (JessieCode именует элементы по переменным;
  закреплённые и скрытые элементы не снимаются). В редакторе отпускание точки —
  транзакция документа, поэтому работает отмена; во вьюере перетаскивание не
  сохраняется. Глайдер восстанавливается проекцией координат на свою кривую.
- Программное `slider.setValue()` требует двух `board.update()`, чтобы глайдер
  перепроецировался; перетаскивание указателем обновляет всё за один проход.
- В jsdom доска работает с `renderer: 'no'` — юнит-тесты не нуждаются в
  браузере. Шум JSXGraph про `matchMedia` в jsdom безвреден.
- Пакет `jsxgraph` не экспортирует `distrib/jsxgraph.css`; нужные правила
  продублированы в `src/styles.css`.
- Для ядра понадобились три атрибута в allowlist санитайзера (и в Python-копии).
  Это временно: точка расширения, через которую возможность объявляет свои
  атрибуты и гидрацию во вьюере, — задача на следующий PR.

## Не сделано

- Палитра инструментов в диалоге (точка, отрезок, окружность, слайдер) — пока
  только текст JessieCode.
- Статический SVG-фолбэк в экспортируемом HTML.
- Цвета JSXGraph через токены `--rte-*` и тёмная тема.
- Доступность точек (`tabIndex`, `aria.label`) и e2e; сдвиг точки с клавиатуры пока не
  попадает в состояние (слушается только отпускание указателя).
- Ограничение длины скрипта и код ошибки `invalid-geometry`.
